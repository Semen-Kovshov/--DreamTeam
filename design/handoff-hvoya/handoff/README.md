# Тренажёр переговоров — дизайн-комплект «хвоя» (v1 · 19.08.2026)

Всё, что нужно, чтобы собрать дизайн по выбранному направлению 3a.

## Состав
- **Варианты дизайна — Партия.dc.html** — интерактивные эталоны-макеты (открыть в браузере; нужен support.js рядом).
  Актуальное: базовый экран партии **3a**, все экраны и состояния **4a–4i**, иконки **1d**. Ходы 1–2 — история поисков.
- **Дизайн-спецификация (хвоя).dc.html** — печатаемая спецификация (палитра, типографика, тени,
  компоненты, раскладки, состояния, движение, чек-лист приёмки). Экспортируется в PDF из браузера.
- **handoff/tokens.css** — токены и готовые классы компонентов (кнопки, чипы, метрики, таймер, анимации).
- **handoff/icons/*.svg** — 6 иконок действий-мелочей (20×20, stroke 1.5, currentColor):
  water, notebook, phone, pause, watch, coffee. Красятся цветом кнопки, тёмной теме правки не нужны.

## Шрифты
IBM Plex Sans (400–700) + IBM Plex Mono (400–700), кириллица — Google Fonts.

## Контракт растровых ассетов (из §4 исходного ТЗ, без изменений)
- `frontend/public/scenes/<id>.jpg` — 4 фона, 1920×1080, q80, ≤400 КБ (salary / supplier / discount / rent);
  нижняя треть спокойная, центр свободен, поверх кладётся виньетка.
- `frontend/public/sprites/<id>/<mood>.png` — 16 спрайтов, 900×1200, альфа; mood: calm / pleased / tense / angry;
  поза и свет между эмоциями не меняются. Рендер ~46% высоты экрана, низ = линия стола.
- Иконки действий — можно класть эти SVG. Favicon — знак 32×32 (замена 🤝 в frontend/index.html).

## Порядок работы
1. Подключить tokens.css и шрифты; собрать экраны по разделу 05 спецификации, сверяясь с макетами 4a–4i.
2. Отрисовать/заказать фоны и спрайты по контракту выше — интерфейс подхватит их без правок кода.
3. Прогнать чек-лист приёмки (раздел 10 спецификации) и проверку эмоций из §5 ТЗ.
