# Разбор задачи

Кейс: интерактивный симулятор для развития навыков делового общения и ведения
переговоров. Исход переговоров должен зависеть от выбранной стратегии,
формулировок, аргументации и других коммуникативных факторов. Формат, механики
и сценарии — на усмотрение команды.

Критерии оценки из постановки и что мы противопоставляем каждому:

| Критерий | Наш ответ |
|---|---|
| Оригинальность концепции | Не дерево диалогов и не «чат с ботом»: свободная речь игрока → распознанные приёмы → детерминированный переговорный движок → объяснимый исход. Каждое изменение состояния имеет причину, и она показывается |
| Актуальность | Переговоры — универсальный навык; тренажёр безопасно отрабатывает то, что в жизни стоит денег и отношений |
| Вариативность сценариев и механик | Сценарий — это данные (JSON), а не код: интересы, рычаги, персона, события. Три персоны оппонентов, события посреди игры, режимы «с подсказками / свободный / экзамен» |
| Качество UX | Бриф с картой подготовки (цель, BATNA), живые индикаторы состояния оппонента, подсказки трёх техник на выбор, разбор с радаром компетенций и аннотированной стенограммой |

## Ключевое решение

Главный риск кейса — «симулятор» вырождается в болталку с LLM: исход
непредсказуем, к защите не привязать, маленькая локальная модель галлюцинирует.

Поэтому переговоры считает **детерминированное ядро**, а LLM работает только
языковым слоем на входе и выходе:

1. **Вход.** Реплика игрока классифицируется в структурированные «ходы»
   (открытый вопрос, аргумент, уступка, ультиматум, …) + извлекаются числа
   предложения. LLM с JSON-схемой, при недоступности — эвристики.
2. **Ядро.** Правила меняют состояние оппонента (доверие, напряжение, аппетит,
   терпение, раскрытые интересы) и выбирают его тактику. Всё воспроизводимо
   и объяснимо — как провенанс значений в соседних проектах.
3. **Выход.** Тактика («отклонить, встречное 178, устало») озвучивается LLM в
   голосе персоны; числа в реплике проверяются по белому списку, при сбое —
   шаблонные фразы из данных сценария.

Симулятор полностью работает без сети и без LLM (эвристики + шаблоны) — это
страховка защиты и режим для автотестов.

## Границы

- Одиночная игра против виртуального оппонента; мультиплеер и голос — вне рамок.
- Русский язык интерфейса и распознавания.
- Базы данных нет: сессии в памяти процесса со снимками на диске (партия
  переживает рестарт бэкенда), журнал завершённых игр — в файле.

## Риски

| Риск | Смягчение |
|---|---|
| Маленькая модель плохо классифицирует | Схема с enum'ами и короткий промпт; эвристики как запасной путь; классификация проверяется тестами на корпусе реплик |
| Модель выдумывает числа в озвучке | Белый список чисел из намерения; при расхождении повтор, затем шаблон |
| Ответ LLM медленный (десятки секунд) | Два коротких промпта вместо одного большого; индикатор «оппонент печатает»; режим без LLM |
| «Игрок молчит/пишет не по делу» | Ход off_topic: оппонент возвращает к теме, терпение тратится |
