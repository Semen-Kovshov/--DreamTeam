# Презентация проекта

`Вторая сторона — ЛЦТ 2026.pptx` — 18 слайдов для защиты, свёрстаны в
**официальном шаблоне хакатона** (`ресурсы/ЛЦТ2026 Шаблон презентации.pptx`).
Дизайн шаблона живёт на его слайдах-заготовках — фоны, карточки, мокапы
ноутбука и телефона, — поэтому колода не рисуется с нуля: `build.py` берёт
заготовки, подставляет в них тексты и скриншоты, удаляет лишние слайды и
выстраивает оставшиеся в нужном порядке.

Структура следует обязательным блокам шаблона: титульный слайд → о команде и
сути решения → состав команды → история команды → «Коротко о решении» → и
дальше презентация решения: проблема, аудитория, путь пользователя, движок,
методики, демо, контур администратора, мобильный сценарий, цифры,
уникальность, границы и планы, запуск для жюри.

**Скриншоты настоящие** — сняты с работающего стенда, а не нарисованы. Слайд
«Цена стратегии» показывает два разбора одного и того же сценария: слабая линия
(принял первое предложение — 49 баллов, сделка хуже своей альтернативы) и
сильная линия из теста `test_good_game_reaches_deal` (90 баллов, взято 87%
зоны возможного соглашения).

## Как пересобрать

Поднять стенд:

```bash
backend/.venv/Scripts/python.exe -m uvicorn app.main:app --port 8030 --app-dir backend
```

Снять экраны (проходит партию через интерфейс: каталог, бриф, партия, журнал,
разбор, админка, мобильные экраны):

```bash
backend/.venv/Scripts/python.exe docs/presentation/shots.py docs/presentation/shots
```

Снять сильную партию для слайда сравнения:

```bash
backend/.venv/Scripts/python.exe docs/presentation/shots.py docs/presentation/shots strong
```

Собрать колоду:

```bash
backend/.venv/Scripts/python.exe docs/presentation/build.py
```

Сильная партия играется в офлайн-режиме — `shots.py` подменяет `use_llm` в
запросе создания сессии. Так линия из теста воспроизводится ход в ход и снимок
не зависит от того, как в этот раз сработала локальная 4B; с живой моделью та
же линия тоже закрывается сделкой, просто медленнее.

Зависимости сборки: `playwright` (плюс `playwright install chromium`),
`python-pptx`, `pillow` — ставятся в `backend/.venv`.

## Что дописать руками

Данные команды скрипт не выдумывает — на их местах в колоде стоят маркеры
`⟨…⟩`. Их правят в начале `build.py` (`TEAM`, `MEMBERS`, `TEAM_ABOUT`,
`TEAM_STORY`) с пересборкой — или прямо в PowerPoint:

- титульный слайд — название команды;
- слайд «Команда» — ФИО, роли, telegram, телефоны, место работы или учёбы,
  плюс фотографии в пустые рамки карточек;
- слайд «О команде» — капитан, число участников, город, краткая история.

Логотипа постановщика задачи (ОЭЗ ППТ «Алабуга») на титульном слайде нет —
файла логотипа в ресурсах не было.
