# UI-спецификация для дизайна

> **Статус: дизайн и арт внедрены полностью.** Действующая дизайн-система —
> «хвоя», комплект в [`design/handoff-hvoya/`](../design/handoff-hvoya/):
> токены, печатаемая спецификация, эталоны-макеты (3a, 4a–4i), иконки действий.
> Интерфейс собран по ней (акцент #1f7a6f, IBM Plex Sans/Mono — локально).
> Растровые ассеты по контракту §4 поставлены 19.08 (генерация по
> `docs/07-art-prompts.md`): 4 сцены, 16 спрайтов эмоций, фирменный знак —
> лежат в `frontend/public/` (scenes/, sprites/, favicon.png).
>
> **Ревизия 19.08 (вечер), по решению владельца продукта:** пиктограмм в
> интерфейсе нет — кнопки действий подписаны словами (Вода, Блокнот, Телефон,
> Пауза, Часы, Кофе), аватары — буквенные монограммы, как в эталонах 4a/4c.
> Гарнитура одна на весь продукт: IBM Plex Sans 300–700 (лайт — вторичные
> описания, болд — заголовки и значения; цифровые блоки — тем же шрифтом с
> tabular-nums). IBM Plex Mono из комплекта не используется.

Документ для художника/дизайнера. Интерфейс уже работает на плейсхолдерах
(градиенты и эмодзи); всё, что вы нарисуете, подключается **без правок кода** —
достаточно положить файлы по путям из §4. Пока файла нет, интерфейс сам
откатывается на плейсхолдер, поэтому ассеты можно отдавать порциями.

## 1. Общий стиль

Продукт — тренажёр деловых переговоров в подаче **лайт-новеллы**: сцена,
персонаж крупным планом, диалоговое окно снизу. Настроение — «деловая
графическая новелла»: спокойные среды офисов, живые персонажи, никакого аниме-
гротеска; аудитория — взрослые специалисты, тон уважительный.

Палитра интерфейса (уже в коде, менять по согласованию):

| Роль | HEX |
|---|---|
| Фон страницы | `#f9f9f7` |
| Поверхность (карточки, VN-окно) | `#fcfcfb` (в сцене — с прозрачностью 90–95% и blur) |
| Текст основной / вторичный / приглушённый | `#0b0b0b` / `#52514e` / `#898781` |
| Линии | `#e1e0d9` |
| Акцент (действия игрока, доверие) | `#2a78d6`, тёмный `#1c5cab`, светлый `#cde2fb` |
| Статусы: хорошо / внимание / серьёзно / критично | `#0ca30c` / `#fab219` / `#ec835a` / `#d03b3b` |

Шрифт — системный sans (`system-ui / Segoe UI`); если предложите фирменную
пару — заголовочный + текстовый, кириллица обязательна.

## 2. Экраны

### 2.1 Каталог
Сетка карточек сценария (портрет-эмодзи → ваша иконка/арт персонажа,
категория, название, описание, сложность точками, навыки-чипы) + журнал
прошлых партий. Дизайн-свобода: карточки могут получить арт-подложку
(см. §4 фоны — можно кропы тех же сцен).

### 2.2 Бриф
Портрет персонажа, ситуация, выбор режима (3 карточки: Обучение / Свободный /
Экзамен), кнопка «Начать переговоры». Хорошее место для крупного арта персонажа.

### 2.3 Партия (главный экран, VN)

Раскладка (десктоп 1280×720 и выше):

```
┌──────────────────────────────────────────────────────────────┐
│ HUD-инд.(слева):        [сцена-фон]        HUD (справа):     │
│ доверие/напряж./терпение                   имя+настроение    │
│ «на столе» + Принять/Выйти                 Журнал|Бриф|Подск.│
│                    [ПЕРСОНАЖ  спрайт]                        │
│                     (низ у VN-окна)        [подсказки ×3]    │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │      ряд действий: 🥛 📓 📱 🤫 ⌚ ☕  (круглые кнопки)      │ │
│ │  Имя говорящего · бейдж источника          ⏱ таймер(free)│ │
│ │  Текст реплики (печатается по буквам, клик — показать всё)│ │
│ │  ваш ход: [чипы приёмов] [дельты] [⏱ N с]                │ │
│ │  [поле ввода……………………………………………] [Сказать]                │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

Состояния, которые надо учесть в дизайне:

- **ожидание ответа**: имя → «…», текст → «обдумывает ответ…» с точками;
- **событие**: карточка-вставка сверху по центру (янтарная) с крестиком;
- **финал**: затемнение сцены + центральная карточка «Партия завершена →
  Разбор»;
- **режим экзамена**: индикаторы скрыты (панель с текстом-заглушкой), чипы
  приёмов не показываются;
- **таймер (только средний режим)**: серый → оранжевый (75 с) → красный (150 с);
- **настроение персонажа** — плашка справа сверху: точка-индикатор + подпись
  («спокоен/расположен/напряжён/на взводе») и сам спрайт (см. §4.2).

Оверлеи «Журнал» (вся переписка с чипами) и «Бриф» (карта подготовки) —
правые панели ~420px.

### 2.4 Разбор
Продуктовый экран (не VN): герой-счёт, 5 баров компетенций с комментариями,
шкала ZOPA, ключевые моменты, рекомендации, стенограмма (включая строки-ремарки
действий и время ответа в среднем режиме). Дизайну достаточно типографики и
иконок; графики уже соответствуют дизайн-системе.

## 3. Механики, влияющие на дизайн

- **Действия-мелочи** (6): налить воды, записать в блокнот, взглянуть в
  телефон, выдержать паузу, посмотреть на часы, пододвинуть кофе. Сейчас —
  эмодзи в круглых кнопках; нужен набор из 6 иконок в едином стиле
  (моно-линия, 20×20 внутри кнопки 40×40). Состояния: обычное / hover /
  недоступно (кулдаун — приглушение 35%).
- **Печать текста**: реплика появляется по ~2 символа за кадр, курсор-палочка
  мигает; клик по окну — показать целиком.
- **Дыхание спрайта**: лёгкое покачивание (уже в коде); при «на взводе» —
  короткая дрожь. Резких аниме-эффектов не нужно.

## 4. Ассеты и контракт путей

Все файлы кладутся в `frontend/public/` (после сборки попадают в раздачу).
Идентификаторы сценариев: `salary`, `supplier`, `discount`, `rent`.

### 4.1 Фоны сцен — 4 шт.

`frontend/public/scenes/<id>.jpg` · **1920×1080**, JPG q80, ≤ 400 КБ.

| id | Сцена |
|---|---|
| `salary` | Переговорная IT-компании: стекло, маркерная доска, вечерний свет |
| `supplier` | Офис-цех обжарщика кофе: тёплое дерево, мешки зерна, ростер на фоне |
| `discount` | Рабочее место у окна, видеозвонок: монитор не виден зрителю |
| `rent` | Кабинет владельца бизнес-центра: массивный стол, жалюзи, грамоты |

Требования: нижняя треть кадра — спокойная (её закрывает VN-окно), центр —
свободен под персонажа, без людей и читаемого текста, лёгкая глубина резкости.
Поверх кода накладывается виньетка снизу (20% чёрного градиента) — учитывайте.

### 4.2 Спрайты персонажей — 4 персонажа × 4 эмоции = 16 шт.

`frontend/public/sprites/<id>/<mood>.png` · **PNG с альфой, 900×1200**
(портрет по пояс), персонаж по центру, низ кадра = линия стола. В кадре
рендерится высотой ~46% экрана.

| id | Персонаж | Типаж |
|---|---|---|
| `salary` | Ирина, руководитель отдела продуктов, ~40 | сдержанная, деловой костюм, лёгкая усталая ирония |
| `supplier` | Сергей, коммерческий директор обжарщика, ~45 | напористый, борода, фартук поверх рубашки |
| `discount` | Марина, операционный директор клиента, ~35 | мягкая, кардиган, виновато-вежливая |
| `rent` | Аркадий Петрович, владелец БЦ, ~60 | хозяйственный, жилет, отеческий прищур |

Эмоции (`<mood>`): `calm` — нейтрально-деловая; `pleased` — расположен,
полуулыбка; `tense` — напряжён, поджатые губы/скрещенные руки; `angry` — на
взводе, жёсткий взгляд. Поза и свет между эмоциями не меняются (переключение
мгновенное) — меняются лицо и пластика рук.

### 4.3 Прочее

- Иконки действий — 6 шт., SVG (см. §3). Пока эмодзи.
- Портреты для каталога/брифа — можно кропы спрайтов `calm` 1:1.
- Favicon 🤝 → фирменный знак 32×32 (замена в `frontend/index.html`).

## 5. Как проверить свою работу

1. Положите файлы по путям §4 (можно частично — остальное на плейсхолдерах).
2. `npm run build --prefix frontend` из корня проекта (или попросите — соберём).
3. Открыть http://localhost:8030 → выбрать сценарий → партия.
4. Эмоции быстро проверяются грубостью («Это несерьёзно, вы издеваетесь?») —
   персонаж должен дойти до `tense`/`angry`; кофе и вопросы вернут `pleased`.
